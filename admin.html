Masukkan URL project Supabase dan publishable/anon key. Keduanya boleh digunakan di website publik jika kebijakan RLS pada database sudah diterapkan. Jangan pernah memasukkan service_role key di sini.

Koneksi disimpan hanya di browser perangkat ini. File admin ini tidak menyimpan kata sandi.

Gunakan email dan kata sandi akun admin yang sudah dibuat di Supabase Authentication.
